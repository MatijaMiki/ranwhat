Privacy

Privacy: the tool and this website

The first half is about the ranwhat command-line tool. The second is about ranwhat.com.

01 / Boundary

Nothing leaves the machine unless you ask.

Not a policy but an architecture. Anything touching a secret runs locally. live, update and the --pull-usage flag go online, and only when you run them.

Stays local

Credentials, prompts, tool arguments, file contents, customer records. The CLI holds a provider token in memory for one call and never writes it down. The only token it stores is your own subscription token, and only if you run update --save-token (mode 0600).

Goes online, when you ask

live and --pull-usage call the provider that issued each token, and nothing else. update, for Plus subscribers, sends the subscription token to feed.ranwhat.com and nothing else. A hosted dashboard, when one exists, would receive derived metadata only: what tool, what authority, whether it was reversible, with payloads hashed in place.

Read-only Scans introspect scopes. They never exercise a permission, and never request a write-scoped credential to run.
Auditable Pure Python standard library. No dependency tree to review before you point it at your own keys.

Your rights

Under the GDPR you can ask what we hold about you, correct it, have it deleted, or object to it being processed at all. Write to the address above. If we handle that badly you can complain to AZOP, the Croatian data protection authority.

Changes

When this notice changes the commit history shows exactly what changed and when, which is more than most privacy pages can offer. It lives in the same public repository as the site.

The install is not tracked

Installing ranwhat, and running check, watch, clean, scan or demo, sends us nothing. There is no licence check, no version ping, no crash reporter. update is the one command that talks to our server, and only when you run it. We do not know how many people use it, which is occasionally inconvenient and entirely the point.
