ranwhat / Commands / Watch

ranwhat watch

See the risky commands Claude Code already ran.

ranwhat watch reads what Claude Code and eleven other coding agents have already written to disk, the audit trail they keep anyway, and reports the nine kinds of action worth a second look. It changes nothing.

$ ranwhat watch --days 30
Install
01 / Detection

Nine things worth interrupting you for.

This isn't antivirus. There's no adversary and no signature, because you asked the agent to do things. So it doesn't guess whether an action was allowed. It raises the ones you'd want to know about either way.

RuleSeverityWhy it's on the list
Credential access
.env · ~/.aws/credentials · id_rsa		 Critical Read a file whose only purpose is holding secrets. The contents are now in a context you don't control, and in the transcript too: find and mask them with ranwhat clean. Then block the next read.
Secret-shaped string in a tool call
sk_live_… · ghp_… · AKIA…		 Critical A credential-shaped value appeared verbatim in a tool call. Even if the call was benign, the value is now in the transcript.
Package or release published
npm publish · twine upload · docker push		 Critical Something reached a registry other people install from. Supply-chain reach, usually irreversible.
Cloud resource destroyed or modified
terraform destroy · kubectl delete · aws iam attach-…		 Critical A write or delete against live infrastructure, including IAM changes, terraform apply -auto-approve and DROP TABLE.
Financial API called
stripe charges · refunds		 Critical With a live key, each of these moves real money.
Log or history tampering
history -c · cloudtrail stop		 Critical An action whose effect is removing the record of other actions.
Destructive git
push --force · reset --hard		 High History rewriting. The class of action that destroys the record of what else happened.
Recursive deletion
rm -rf · find -delete		 High Recoverable only if something else was backing it up. Severity follows the target: rm -rf build is not reported, rm -rf ~/Documents is high, rm -rf "$HOME" is critical.
Local file sent to the network
curl -d @file · curl -F file=@…		 High File contents sent outbound in one command. That shape, whatever the intent.

watch looks back over history after the fact, so it is not live monitoring of Claude Code or any other agent, and it blocks nothing. To have a call these rules rate high or critical wait for your yes before Claude Code runs it, install the opt-in hook. For a record kept while the agent works, add a hook or OpenTelemetry, as the Claude Code audit log guide shows.

02 / Precision

A watcher that cries wolf gets muted in a day.

So three things that look dangerous are not treated as actions. The first watch build, run on a real machine's history, flagged 6 findings, and these were the 3 false positives among them.

grep "rm -rf" src/

Searching for a string isn't running it. Search tools without an action flag are suppressed.

python3 -c "…rm -rf…"

The payload is Python source. bash -c is the exception: that really is shell, so it recurses in.

cat > f.sh <<'EOF'

A heredoc body is data being written. Writing a script that contains a command isn't running it.

On real history A later release reported 15 findings on one machine's 90-day history. Eleven were true deletions of build and temp directories that nobody would want to read, so deletions are now ranked by target. After that change the same history gave 4, and all four were real.
Evidence Every finding carries surrounding context. rm -rf on its own tells you nothing. The target is the point. A secret in it is masked: every value clean finds anywhere in your history, known by an index of salted fingerprints in ~/.ranwhat/known.
Test suite Written as invariants rather than expected output.
03 / Sources

Reads the agents already on your machine.

No wrapper, no proxy, nothing in your critical path unless you install the hook. It reads what each agent already wrote to disk, all of them by default.

AgentLocationFormatStatus
Claude Code ~/.claude/projects/*/*.jsonl, and each session's subagents/ ($CLAUDE_CONFIG_DIR) JSONL Shipped
Codex ~/.codex/sessions/ and archived_sessions/ ($CODEX_HOME); its prompt history, shell snapshots and thread index searched for secrets JSONL; SQLite read only; .jsonl.zst read only, on Python 3.14 or with the zstd command Shipped
Gemini CLI ~/.gemini/tmp/<project>/chats/ ($GEMINI_CLI_HOME) JSONL, JSON Shipped
GitHub Copilot CLI ~/.copilot/session-state/<session>/events.jsonl ($COPILOT_HOME) JSONL Shipped
Qwen Code ~/.qwen/projects/<project>/chats/, and older tmp/<hash>/chats/ ($QWEN_RUNTIME_DIR, $QWEN_HOME) JSONL, JSON Shipped
Grok Build ~/.grok/sessions/<folder>/<session>/updates.jsonl ($GROK_HOME) JSONL Shipped
Droid ~/.factory/sessions/ ($FACTORY_HOME_OVERRIDE) JSONL Shipped
Kimi Code ~/.kimi-code/sessions/ ($KIMI_CODE_HOME) JSONL Shipped
Kimi CLI ~/.kimi/sessions/ ($KIMI_SHARE_DIR) JSONL Shipped
Pi ~/.pi/agent/sessions/ ($PI_CODING_AGENT_DIR) JSONL Shipped
Muse Code ~/.local/share/muse/sessions/ ($XDG_DATA_HOME/muse) JSONL Shipped
OpenClaw $OPENCLAW_STATE_DIR/agents/*/agent/openclaw-agent.sqlite (default ~/.openclaw) SQLite, tool calls found by shape; compressed events and cold archives not read yet Shipped, secrets read-only
Meta Muse Meta's cloud Nothing on your machine Cloud only
Grok Bot xAI's cloud Nothing on your machine Cloud only
Amp ampcode.com, for the current Amp Nothing on your machine Cloud only
Cursor Its local history Not read yet Next

Each agent is read from where it keeps its history, and the variable in brackets moves it for ranwhat as it moves it for the agent. --source ID reads one agent, --path ID=PATH reads one from elsewhere, and ranwhat sources lists where it looked and what it found.

Databases and compressed files are only ever read. OpenClaw keeps its history in SQLite, so clean finds its secrets but cannot mask them there. Not read yet: the large tool outputs Claude Code stores in <session>/tool-results/, and ~/.claude/history.jsonl. Where Claude Code keeps your history lists the files a session leaves behind.

Meta Muse, Grok Bot and the current Amp keep their history in their vendor's cloud, so there is nothing on your machine to read. Muse Code and Grok Build, Meta's and xAI's coding CLIs, are read. Cursor is next, once its format is checked against a primary source.

04 / Output

Machine-readable, and one command for both halves.

ranwhat watch --json prints one record per flagged call.

Record source, session, project, timestamp, tool_name, tool_call_id, payload_hash, severity, and every rule the call tripped, each with its evidence.
Once each A call replayed by a resumed session is reported once, not once per transcript that carries it.
Both halves ranwhat check runs watch and clean in one pass, and changes nothing.
