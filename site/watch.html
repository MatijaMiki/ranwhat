ranwhat watch

See the risky commands Claude Code and OpenClaw already ran.

ranwhat watch reads what Claude Code and OpenClaw already wrote to disk and reports nine kinds of action: credential reads, secret-shaped strings in tool calls, package publishing, cloud resource changes, payment API calls, log or history tampering, destructive git, recursive deletion, and local files uploaded with curl.

$ ranwhat watch --days 30
Install
01 / Detection

Nine things worth interrupting you for.

This isn't antivirus. There's no adversary and no signature, because you asked the agent to do things. So it doesn't guess whether an action was allowed. It raises the ones you'd want to know about either way.

RuleSeverityWhy it's on the list
Credential access
.env · ~/.aws/credentials · id_rsa		 Critical Read a file whose only purpose is holding secrets. The contents are now in a context you don't control, and in the transcript too: find and mask them with ranwhat clean. Then block the next read.
Secret-shaped string in a tool call
sk_live_… · ghp_… · AKIA…		 Critical A credential-shaped value appeared verbatim in any part of the call. Even if the call was benign, the value is now in the transcript.
Package or release published
npm publish · twine upload · docker push		 Critical Something reached a registry other people install from. Supply-chain reach, usually irreversible.
Cloud resource destroyed or modified
terraform destroy · kubectl delete · aws iam attach-…		 Critical A write or delete against live infrastructure, including IAM changes, terraform apply -auto-approve and DROP TABLE.
Financial API called
stripe charges · refunds		 Critical With a live key, each of these moves real money.
Log or history tampering
history -c · cloudtrail stop		 Critical An action whose effect is removing the record of other actions.
Destructive git
push --force · reset --hard		 High History rewriting. The class of action that destroys the record of what else happened.
Recursive deletion
rm -rf · find -delete		 High Recoverable only if something else was backing it up. Severity follows the target: rm -rf build is not reported, rm -rf ~/Documents is high, rm -rf "$HOME" is critical.
Local file sent to the network
curl -d @file · curl -F file=@…		 High File contents sent outbound in one command. That shape, whatever the intent.
02 / Precision

A watcher that cries wolf gets muted in a day.

So three things that look dangerous are not treated as actions. Each of these was a real false positive on real history, found by pointing the first version at a live machine.

grep "rm -rf" src/

Searching for a string isn't running it. Search tools without an action flag are suppressed.

python3 -c "…rm -rf…"

The payload is Python source. bash -c is the exception: that really is shell, so it recurses in.

cat > f.sh <<'EOF'

A heredoc body is data being written. Writing a script that contains a command isn't running it.

On real history 15 findings before these rules, 4 after. Three were false positives; eleven were true deletions of build and temp directories that nobody would want to read.
Evidence Every finding carries surrounding context. rm -rf on its own tells you nothing. The target is the point.
Test suite Written as invariants rather than expected output.
03 / Sources

Reads the agents already on your machine.

No wrapper, no proxy, nothing in your critical path. It reads what the agent already wrote to disk.

AgentLocationFormatStatus
Claude Code ~/.claude/projects/*/*.jsonl JSONL transcripts Shipped
OpenClaw $OPENCLAW_STATE_DIR/agents/*/agent/openclaw-agent.sqlite SQLite, tool calls found by shape Shipped
Codexn/a Native OpenTelemetry Next
OTLP receiverlocalhost Any agent emitting GenAI spans Next

OpenClaw's state directory defaults to ~/.openclaw. Its database layout is documented, and says to rebuild history through OpenClaw's transcript accessor, because some events are stored compressed. So the adapter pins no table names: it finds tool calls by shape, opens the database read-only because it belongs to a running agent, and falls back to a copy if the agent holds a WAL lock.

Three limits, stated here until they are fixed. OpenClaw's whole stored history is read, since --days applies to Claude Code only. Events OpenClaw stores compressed are not read yet. Claude Code subagent transcripts, in <session>/subagents/, are not read yet either. Where Claude Code keeps your history lists the files a session leaves behind.

04 / Output

Machine-readable, and one command for both halves.

ranwhat watch --json prints one record per flagged call, with secrets masked in the evidence.

Record source, session, project, timestamp, tool_name, tool_call_id, payload_hash, severity, and every rule the call tripped, each with its evidence.
Once each A call replayed by a resumed session is reported once, not once per transcript that carries it.
Both halves ranwhat check runs watch and clean in one pass, and changes nothing.
Audit log Turn these records into an audit log, or add a hook or OpenTelemetry to keep one from now on: Claude Code audit log.
Deletions Filtering this for deletions, and what rewind can and cannot restore: Claude Code deleted my files.
