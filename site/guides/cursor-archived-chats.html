How to find and restore archived chats in Cursor

An archived chat is hidden, not deleted. Cursor keeps it in the same database as every other chat and only hides it from the sidebar, so you can show it again, restore it, or read it straight from disk.

Cursor has no official page on archiving. The menu steps come from Cursor staff answers on the Cursor forum, and the on-disk part from ranwhat's Cursor reader and the forum reports listed under Sources. Cursor's sidebar changes often, so names may differ in your version. Published 26 November 2026.

01 / Show

Where do archived chats go in Cursor?

To a collapsed Archived group at the bottom of the chat list. It is closed by default, so it looks like the chats are gone.

Editor layout Scroll to the bottom of the chat list and expand Archived.
Agents window Open the sidebar's filter and choose Filter by → Status → Archived. On builds with a Customize Sidebar button, turn on Archived Chats there.
Search Open the command palette (Cmd/Ctrl+Shift+P) and type a few words you remember from the chat. Archived chats show up in the results too, which is often quicker than the filters.
02 / Restore

How do I unarchive a chat in Cursor?

Hover the archived chat and click its restore icon, or right-click it and choose Restore.

The chat moves back into the normal list with all its messages and tool calls. Nothing is lost while a chat is archived: archiving only flips a flag, which is why restoring is instant.

03 / Why

Why did my Cursor chat get archived?

Usually by a shortcut: in the Agents window, Cmd/Ctrl+Shift+E archives the chat you are in.

In the editor the same keys open the Explorer, so going between the two windows makes it easy to archive a chat by accident. If a chat vanished just after you reached for the file tree, look in Archived first.

04 / Disk

Are archived Cursor chats still on my disk?

Yes. They stay in state.vscdb with every other chat, messages and tool calls included.

The chat list lives in the ItemTable row composer.composerHeaders, one header per chat, and an archived header has isArchived: true (forum reports, see Sources). The chat itself is still in cursorDiskKV under composerData:<id>, with its messages under bubbleId:<id>:*. To list archived chats from a copy of the database: 

# macOS; on Linux use ~/.config/Cursor/User/globalStorage
cd ~/Library/Application\ Support/Cursor/User/globalStorage
mkdir -m 700 ~/cursor-copy
cp state.vscdb state.vscdb-wal ~/cursor-copy/ 2>/dev/null

# archived chats: id and name
sqlite3 -readonly ~/cursor-copy/state.vscdb "
  SELECT json_extract(c.value,'$.composerId'), json_extract(c.value,'$.name')
  FROM ItemTable, json_each(ItemTable.value,'$.allComposers') AS c
  WHERE key='composer.composerHeaders'
    AND json_extract(c.value,'$.isArchived')=1"

# done: the copy holds your Cursor login too
rm -r ~/cursor-copy

Never edit the live database to unarchive a chat: use Restore in Cursor. Field names are undocumented and change between Cursor versions, so if the query returns nothing, your build may store the list differently.

05 / Ran

Can I see what an archived chat's agent ran?

Yes. uvx ranwhat watch --source cursor reads every chat in state.vscdb, archived ones included, read-only.

$ uvx ranwhat watch --source cursor
Install

It lists the risky shell commands, file deletions and credential reads, telling apart calls that ran from calls you declined. Archiving hides a chat from you, but what its agent did on your machine still happened.

06 / Delete

Is archiving the same as deleting?

No. Archive hides a chat; delete removes it from the list.

Even a deleted chat can leave rows behind: forum users report a deleted chat whose header or body stayed in state.vscdb. If a chat ever showed a password or API key, archiving or deleting it does not help. Rotate the key at the provider, as rotating a leaked key explains.

07 / Questions

Common questions about archived chats in Cursor

How do I see archived chats in Cursor?

Expand the Archived group at the bottom of the chat list. In the Agents window, use Filter by → Status → Archived, or turn on Archived Chats under Customize Sidebar.

Do archived chats in Cursor expire?

Cursor documents no retention period, and archived chats stay in state.vscdb until you delete them.

Does Cursor remember archived chats in new conversations?

Not by itself. A new chat does not read old ones, archived or not. Cursor's Memories and rules are separate features and are not built from your chat list.

My chats disappeared and are not in Archived. Where are they?

Check that you opened the same folder: chats record their workspace. If the list is empty after an update, the chats are usually still in state.vscdb; Cursor chat history shows how to check a copy.
